Production builds appear first, followed by the latest daily revisions. Workflow and Operators update independently. Suite includes both tools, with separate component downloads. Each package contains its listed Houdini targets; you do not need to download other builds.

Download the ZIP from Google Drive and its signed release manifest, then choose Import Release in Pragmatic Manager. The manager checks the release signature, compatibility and archive integrity before installation.

Install into a separate version folder. Select the version you want in Pragmatic Manager, then restart Houdini. Your settings and license are retained.

Operators releases contain a fixed set of HDA definitions. Use Houdini's Asset Manager for individual definitions. Older scenes may require definitions from an earlier release.

Older daily builds may be retired after 30 days. Keep a local copy of a build you need for a project. Production builds and explicitly pinned builds are retained.
