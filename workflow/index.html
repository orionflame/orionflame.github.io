Build in context

Your network, right where you work.

Bring the network over your viewport, make your changes, and return to the result. Pair the overlay with context-sensitive hotkeys and mouse actions to keep everyday node work close at hand, with less movement between panes.

  • Adjustable overlay opacity
  • Quick show and hide interaction
  • Context-sensitive actions and optional connected-node dragging

Edit a graph while keeping the visual result in context.

Edit with less friction

Give complex controls room to make sense.

Work through parameters in a configurable editor built around Houdini's controls. Adjust values, navigate folders, edit ramps and multiparms, and keep code alongside the node it belongs to. Tune the interface's type, spacing, and presentation to suit the way you work.

  • Direct numeric entry and dragging
  • Folders, ramps, and multiparms
  • Configurable labels, fonts, and layout

Reduce the effort of reading and operating the interface during repeated parameter iteration.

Write where you create

Four languages. One focused editing experience.

Move between VEX, OpenCL, Python, and C++ in a Monaco-based editing environment integrated with Parm Editor. Language-aware completion, signatures, and documentation help keep the next step close to the code, with Houdini context supplied to the relevant language service.

  • VEX and OpenCL workflows
  • Python and HOM assistance
  • C++ and HDK editing support

Capabilities differ by language and context. C++ and HDK support requires the appropriate environment.

Understand the result

Know what changed inside your geometry.

Inspect attributes, groups, memory, and volume information in a focused node view. Change markers help surface additions, removals, and possible writes against available input data, so you can investigate what a node produced without starting with a wall of raw values.

  • Geometry and memory summaries
  • Attribute and group change markers
  • Volume and VDB details with touch indicators

Cached inspection can be unavailable or stale. Revision and touch markers indicate possible writes, not exact value differences.

Follow the data

From the whole dataset to the value that matters.

Filter geometry data, focus on selected elements, and inspect structured values in a dedicated spreadsheet. Matrix displays, typed data, volume summaries, and precision controls help turn a broad table into a specific answer.

  • Group and column filters
  • Viewport-selection workflows
  • Matrix, dictionary, and volume views where supported

Context-specific support differs across SOP, LOP, DOP, Copernicus, and legacy COP2 workflows.

Optimize with evidence

Find the cost. Measure the change.

Record Houdini's native performance data, inspect expensive nodes, and compare captures before and after an edit. Move between hotspots, event timelines, and call views to understand where recorded work accumulates and whether your change improved the metric you care about.

  • Ranked hotspots and frame or thread filters
  • Event timelines, call trees, and flame graphs
  • Capture comparison and native .hperf support

Event flame graphs describe attributed event work, not source-level CPU sampling. VEX program reports are a separate capability.

Navigate and create

Find the node. Keep moving.

Search and navigate your scene through a node tree, then find creation tools in a context-aware palette. Explore nested networks, jump to an existing node, or choose a tool, recipe, or compatible preset without losing your place in the task.

  • Name, path, and type search
  • Hierarchy navigation and selection linking
  • Aliases, favorites, and numbered palette results

Saved HDA definition previews are read-only and distinct from live instances. Native tool behavior remains relevant.

Keep performance in view

A glance at the machine behind the scene.

Keep CPU, RAM, GPU, and VRAM readings in view with a compact, customizable HUD. Choose the gauge style, colors, typography, and spacing that fit your workspace, and enable the cook timeline when you want additional cooking context.

  • Four resource gauges where telemetry is available
  • Six visual styles
  • Optional cook timeline

Telemetry availability depends on platform and hardware. System-wide readings are not exact per-node resource consumption.

What is included with Workflow?

Workflow includes the connected workspace tools described on this page, including the Overlay Network Editor and interaction system, Parameter Editor, language-aware code editing, Node Info, Spreadsheet, Profiler, Node Treeview and creation palette, Performance HUD, and their verified supporting controls. Operators is a separate product.

How does the license work?

An individual license is assigned to one named customer, supports one concurrent seat and up to two activated devices, and includes 12 months of update coverage. Eligible releases remain usable permanently. Renewing extends access to newer eligible builds and compatibility updates.

Can I customize the interface?

Yes. Verified options include typography, layout and spacing, colors, supported interaction preferences, overlay settings, and Performance HUD presentation. Available options vary by component.

How is Workflow different from Suite?

Workflow is the workspace and productivity product. Pragmatic Suite combines Workflow with Pragmatic Operators under the broader bundle offer. Operators is not included in a standalone Workflow license.
